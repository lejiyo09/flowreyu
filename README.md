# Paperline PDF Notes

전체 화면에서 PDF를 읽고 주석을 남길 수 있는 가벼운 노트 앱 프로토타입입니다. 중앙의 문서가 작업 영역이 되며, 툴바·페이지 목록·확대/축소·설정은 떠 있는 위젯 형태로 배치됩니다.

## 제공 기능

- 펜, 형광펜, 지우개, 텍스트, 주석 도구를 위한 떠 있는 툴바
- 드래그해서 옮길 수 있는 텍스트 주석과 PDF 파일 이름 가져오기
- 주석 상태를 브라우저 `localStorage`에 상시 자동 저장
- 주석 데이터를 JSON 파일로 내보내는 저장 버튼
- 팜 리젝션, 길게 눌러 도구 UI 열기, 길게 누르기 시간, 다크 모드 설정
- 페이지 목록과 확대/축소 UI

## 실행

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000`을 엽니다.

> 이 프로토타입의 저장 기능은 브라우저 로컬 저장소 및 주석 JSON 내보내기를 사용합니다. 실제 PDF 바이너리에 주석을 병합하려면 PDF 처리 라이브러리와 서버 저장소를 추가하면 됩니다.
