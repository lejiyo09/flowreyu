# Paperline PDF Notes

전체 화면에서 PDF를 읽고 주석을 남길 수 있는 가벼운 노트 앱 프로토타입입니다. 중앙의 문서가 작업 영역이 되며, 툴바·페이지 목록·확대/축소·설정은 떠 있는 위젯 형태로 배치됩니다.

## 제공 기능

- 펜, 형광펜, 지우개, 텍스트, 주석 도구를 위한 떠 있는 툴바
- 실제 PDF 파일 가져오기 및 모든 PDF 페이지 렌더링
- 펜, 형광펜, 지우개, 텍스트 주석으로 PDF 위에 직접 필기
- 주석 상태를 브라우저 `localStorage`에 상시 자동 저장
- 필기와 텍스트 주석을 반영한 새 PDF 파일 내보내기
- 팜 리젝션, 길게 눌러 도구 UI 열기, 길게 누르기 시간, 다크 모드 설정
- 페이지 목록과 확대/축소 UI

## 실행

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000`을 엽니다.

> 브라우저에서 PDF.js와 pdf-lib CDN을 불러옵니다. 내보내기 시 필기 레이어는 PDF 각 페이지에 병합되어 `*-annotated.pdf` 파일로 저장됩니다. 원본 PDF는 변경하지 않습니다.
