# FlexNote — 태블릿용 PDF 필기 웹앱

HTML·CSS·JavaScript(빌드 과정 없음)로 만든 PDF 필기 앱입니다. 기존 프로토타입 코드는 쓰지 않고 새로 작성했습니다.
PDF.js 4.10.38과 pdf-lib 1.17.1은 `vendor/`에 같이 들어 있어서 인터넷 없이도 동작합니다.

## 실행

```bash
cd notes-app
node server.js            # http://localhost:8080
node server.js 8080 --lan # 같은 Wi-Fi의 태블릿에서 접속 (주소가 콘솔에 표시됨)
```

`index.html`을 더블클릭(file://)해서 열면 **동작하지 않습니다.** 브라우저가 ES 모듈과 PDF.js 워커를 막기 때문이고, 이 경우 화면에 안내 문구가 표시됩니다.
`python3 -m http.server`도 쓸 수 있지만, `.mjs` 파일의 MIME 타입이 올바르게 나가는 `server.js`를 권장합니다.

### 갤럭시 탭(S Pen)에서 테스트하는 방법 (권장 순서)

1. **HTTPS 정적 호스팅**: 폴더를 GitHub Pages, Netlify, Cloudflare Pages 중 하나에 그대로 올립니다. 이 방법만 모든 기능(오프라인 설치, 영구 저장 요청)을 쓸 수 있습니다.
2. **USB + adb reverse**: PC에서 `node server.js`를 실행한 뒤 `adb reverse tcp:8080 tcp:8080`을 입력하고, 탭의 Chrome에서 `http://localhost:8080`으로 접속합니다. localhost는 보안 컨텍스트로 취급되므로 기능 제한이 없습니다. PC Chrome의 `chrome://inspect`를 열면 탭의 콘솔도 볼 수 있습니다.
3. **같은 Wi-Fi**: `node server.js 8080 --lan`을 실행하고 `http://<PC IP>:8080`으로 접속합니다. 필기와 저장은 되지만, http라서 서비스 워커(오프라인)와 영구 저장 요청은 동작하지 않습니다.

Chrome 메뉴의 "홈 화면에 추가"로 설치해 두면 전체 화면으로 실행되고, 브라우저 제스처와 겹치는 일이 줄어듭니다.

| 마우스 | 왼쪽 필기, 오른쪽 메뉴, 휠 스크롤, Ctrl+휠 확대 |
| 키보드 | Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y, Delete, P·H·E·L·T·S·K(도구), PageUp/PageDown |

도구: 펜, 형광펜, 지우개(획 단위·부분), 올가미(선택·이동·크기·삭제·복제·색), 텍스트, 도형, **링크**
지우개는 **텍스트·링크·그림·포스트잇을 지우지 않음** (올가미로 선택해 삭제. 지우개 팝업의 "…도 지우기"로 바꿀 수 있음)

### 그림 · 포스트잇
- **그림 넣기**(도구 모음 🖼): 파일 선택, 붙여넣기(Ctrl+V), 화면에 끌어 놓기. 큰 사진은 긴 변 2400px로 줄여 저장(필기와 따로 저장되어 자동 저장이 가볍게 유지). 넣으면 바로 올가미 선택 상태라 끌어서 옮기고 오른쪽 아래 점으로 크기 조절
- **포스트잇**(도구 모음 📝): 화면 가운데에 붙고 바로 글 입력(자동 줄바꿈). 위에 펜으로 써도 됨. 텍스트 도구로 탭하거나 올가미 선택 → "글 편집"으로 수정, 선택 메뉴에서 포스트잇 색 변경
- **포스트잇 삭제**: 띠 오른쪽 끝 **×** 를 펜·손가락으로 탭하면 위에 쓴 필기와 함께 삭제 (실행 취소 가능)
- **포스트잇 접기/펼치기**: 펼친 포스트잇 오른쪽 위 "–"를 탭(펜·손가락)하면 작은 아이콘으로 접히고, 아이콘을 탭하면 펼쳐짐. 포스트잇 위에 쓴 필기도 함께 숨고(지우개도 건드리지 않음), 올가미로 포스트잇을 옮기면 위의 필기도 같이 이동. 선택 메뉴의 접기 버튼·실행 취소도 가능
- 둘 다 PDF 내보내기와 필기 백업(JSON, 그림 포함)에 들어가며, 제스처 동작으로도 지정 가능
- **포스트잇 옮기기**: 포스트잇 윗부분 어두운 띠(접힌 아이콘)를 펜이나 손가락으로 잡고 끌면 위에 쓴 필기와 함께 이동 (어떤 도구를 쓰고 있어도 됨)

### 체크리스트 · 표
- **체크리스트**(도구 모음 ☑): 한 줄 = 한 항목으로 입력. 상자를 펜(어떤 도구든)이나 손가락으로 탭하면 완료/해제(취소선). 텍스트 도구로 탭하면 항목 수정, 순서를 바꿔도 완료 표시는 글을 따라감
- **표**(도구 모음 ▦): 행·열 지정(첫 행은 머리글). 텍스트 도구로 칸을 탭해 입력, Tab/Shift+Tab 으로 다음·이전 칸. 올가미로 선택하면 +행/−행/+열/−열
- **표·체크리스트 손잡이**: 위쪽 어두운 띠를 펜이나 손가락으로 잡고 끌면 위에 쓴 필기와 함께 이동, 띠 오른쪽 **×** 를 탭하면 삭제 (실행 취소 가능). 띠는 화면에만 보이고 PDF 내보내기에는 안 들어감
- 둘 다 올가미로 이동·크기 조절, 위에 펜 필기 가능, 지우개에 지워지지 않음, PDF 내보내기에 포함

### 음성 녹음 · 필기 따라가기 · 받아쓰기
- 위쪽 🎙 버튼 → **녹음 시작**. 녹음하는 동안 쓴 필기(펜·형광펜·도형·글상자)에 녹음 시각이 함께 저장됨
- 녹음을 골라 재생하면 **아직 쓰기 전 필기는 흐리게** 보였다가 재생 위치에 맞춰 나타나고(필기 따라가기), 그 필기가 있는 페이지로 자동 이동(페이지 따라가기)
- 재생할 녹음을 연 상태에서 필기를 탭하면 **그 필기를 쓰던 순간부터** 재생
- **받아쓰기(STT)**: 브라우저 음성 인식(Web Speech API)으로 실시간 전사. 문장을 탭하면 그 시점으로 이동, "포스트잇으로 붙이기" 가능. 크롬은 구글 서버로 음성을 보내므로 **인터넷 필요**(오프라인이면 녹음만 됨)
- 녹음 파일은 IndexedDB에 저장(노트를 지우면 함께 삭제), 내려받기 가능. 재생 중에는 새 필기를 막음
지우개 옵션 **한 번 지우면 이전 도구로**: 지우개로 한 번 지우고 펜을 떼면 지우개 전에 쓰던 도구로 자동 전환 (지우개 팝업 또는 설정 → 지우개에서 켜기)
보조 도구: **자**(모서리를 따라 직선, mm/cm 눈금), **각도기**(호·밑변 따라 그리기, 펜 위치 각도 표시) — 손가락 1개로 이동, 2개로 회전(15° 단위 달라붙음)

### AI 도우미 (Google Gemini API · 본인 API 키)
위쪽 ✦ 버튼. 처음에 **설정 → AI 도우미**에 Gemini API 키(aistudio.google.com → Get API key, 무료 발급)를 넣습니다. 키는 이 기기의 localStorage 에만 저장되고(설정·백업 파일·저장소에는 안 들어감) 브라우저에서 generativelanguage.googleapis.com 으로 바로 전송됩니다. 인터넷이 필요하고, 공용 기기에서는 키를 넣지 마세요.
**키를 코드에 넣어 커밋하지 마세요** — GitHub Pages 로 공개되어 누구나 가져다 씁니다. Google Cloud 콘솔에서 키에 "웹사이트 제한(HTTP 리퍼러: `https://lejiyo09.github.io/*`)"을 걸어 두면 더 안전합니다.
- **키 입력 없이 쓰는 방법 1 (권장)**: 기기마다 한 번 `https://lejiyo09.github.io/flowreyu/#gk=키` 를 열면 그 기기에 키가 저장되고 주소에서 지워집니다 (`#` 뒤는 서버로 전송되지 않음). 이 링크는 본인만 보관하세요.
- **Render 로 배포할 때 (권장)**: Render 대시보드 → 이 사이트 → **Environment** 에 `GEMINI_API_KEY` = 키 를 추가하고, **Settings → Build Command** 를 `node tools/inject-key.js`, **Publish Directory** 를 `.` 로 둔 뒤 다시 배포. 키는 저장소에 안 올라가고 배포된 사이트에만 들어가므로 모든 기기에서 입력 없이 동작합니다 (방문자는 볼 수 있으니 웹사이트 제한을 Render 주소로 걸 것)
- **방법 2**: `js/ai.js` 의 `BUILTIN_KEY = ''` 에 키를 넣으면 모든 사람이 입력 없이 씁니다. 대신 공개 저장소라 키가 노출되므로 Google Cloud 콘솔에서 웹사이트 제한·API 제한(Generative Language API)을 꼭 거세요.
- **회의록 정리·요약**: 녹음 받아쓰기 + 현재 페이지 이미지(손글씨 포함) + 페이지의 글 → 제목·요약·논의 내용·결정 사항·할 일·남은 질문. "포스트잇으로 붙이기", **"할 일을 체크리스트로"**
- **맞춤법·문법**: 선택한 객체(없으면 현재 페이지)의 글상자·포스트잇·체크리스트 항목·표 칸을 교정, 바뀐 점 설명. "고친 글로 바꾸기"(실행 취소 가능, 그 사이 직접 고친 글은 건너뜀)
- **번역**: 같은 대상을 12개 언어로 번역해 그대로 바꾸거나 포스트잇으로 붙이기
- 손글씨 자체를 글로 바꾸지는 않습니다 (회의록에서는 이미지로 읽어 참고만 함)
- 모델: **Gemini 3 Flash**(기본, `gemini-3-flash-preview`) / Flash 최신판(`gemini-flash-latest`) / Flash-Lite. 모두 무료 키로 사용 가능 (Pro 는 무료 키 사용량이 0 이라 뺐음)
- 생각 깊이(빠르게/보통/꼼꼼하게) = Gemini `thinkingLevel` low/medium/high
- 무료 키는 분당·일일 요청 한도가 있어 연속으로 쓰면 잠시 막힐 수 있음

### 페이지
페이지 패널(왼쪽 위 ▦)의 **페이지 추가**(앞/뒤/맨 뒤, 속지, 개수)·**삭제**, 또는 마지막 페이지 아래 "페이지 추가" 버튼.
필기·링크 대상·실행 취소 기록이 새 페이지 번호로 함께 옮겨지고, PDF와 필기가 한 번에(원자적으로) 저장됩니다. 페이지 추가/삭제 자체는 실행 취소되지 않습니다.

### 링크
- PDF에 원래 있는 링크(목차 등)와 웹 링크: **손가락으로 탭** (펜 탭은 필기라서 링크로 이동하지 않음)
- 직접 만들기: 링크 도구로 영역을 그리고 페이지 번호나 웹 주소 지정. 펜으로 탭하면 수정/삭제
- 이동 후 "← 돌아가기"로 원래 위치 복귀. PDF로 내보내면 다른 뷰어에서도 눌리는 링크로 저장

### 오프라인
한 번 접속하면 앱 전체(PDF.js, 한글 PDF용 CMap·폰트 포함)가 기기에 저장되어 **와이파이 없이도 켜집니다** ("오프라인에서도 쓸 수 있도록 준비했습니다" 알림). HTTPS(GitHub Pages) 또는 localhost 에서만 동작합니다.
새 버전이 올라오면 상단에 "업데이트" 버튼이 뜨고, 누를 때만 교체됩니다.

## S Pen 버튼 — 실제 기기 관찰 결과

갤럭시 탭 Chrome(로그 UA: Chrome 154)에서 버튼을 누른 채 터치한 로그를 분석한 결과, **브라우저에 버튼 정보가 전혀 전달되지 않았습니다.**
모든 펜 이벤트가 `buttons=1`(닿음) 또는 `0`이었고 `buttons=2`, `contextmenu`, `auxclick` 은 한 번도 없었습니다. 버튼을 누른 채 친 탭과 그냥 친 탭이 이벤트상 완전히 같습니다.
따라서 이 기기·브라우저에서는 웹 페이지가 S Pen 버튼을 감지할 방법이 없고, 대안으로 **펜 두 번 탭**과 **정지 감지**로 도구 메뉴를 엽니다.

앱은 버튼 신호가 오는 기기(다른 태블릿·브라우저)를 위해 `buttons&2` / `button=2` / `contextmenu`(펜이 마우스 우클릭으로 바뀌어 오는 경우 포함)도 계속 받습니다.
다른 기기에서 확인하려면 설정 → 진단 → **입력 디버그 로그**를 켜고 버튼을 누른 채 터치한 뒤 **복사/저장**하세요. 로그에는 앱이 각 입력을 어떻게 판정했는지(▶ 줄)도 남습니다.

같은 로그에서 손가락 접촉 크기가 43px로 측정되어, 기존 손바닥 판정 기준(40px)이 손가락을 막고 있었습니다 → 기본값 90px로 변경(예전 기본값 쓰던 사용자는 자동 변경).

### 저장 방식
- PDF 원본은 IndexedDB `files` 스토어에 Blob으로 저장합니다(Base64 변환 없음). 메타데이터와 같은 트랜잭션으로 저장되므로 둘 중 하나만 남는 경우가 없습니다.
- 필기는 **페이지 단위** 레코드로 저장하고, 바뀐 페이지만 0.5초 디바운스 후 기록합니다. 앱이 백그라운드로 가거나 페이지를 벗어날 때는 즉시 저장합니다.
- 저장에 실패하면 상단에 "저장 실패"가 표시되고 알림이 뜹니다. 실패한 페이지는 지워지지 않고 남아 있다가 2초, 4초, 8초… 간격으로 다시 저장을 시도합니다.
- 불러올 때 모든 객체를 검증합니다. 손상된 객체는 건너뛰고 몇 개를 건너뛰었는지 알려 줍니다.
- 브라우저가 저장소를 지울 수 있으므로, 설정 → 저장소에서 **영구 저장 요청**과 **필기 백업(JSON) 내보내기·가져오기**를 제공합니다.
- 설정값은 localStorage에 저장합니다.
